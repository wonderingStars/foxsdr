# e1-lockout-range (engine lane E1, row D2; owner decision list of 2026-11-16): the lockout keys of the Scanner body work in a RANGE scan. Before this lane they were drawn dead outside a scan
# of the ticked rows and the engine's SCANNER_EXTRAS 1 and 2 were never sent. Here a range scan runs on the generator with the squelch shut (so it only steps); "Lock out for good" and "Lock out 10 min" send the
# engine's lockout of the frequency the scan is on and the engine says so (fact.scan.lockouts*, read back FROM THE ENGINE), the status text counts them and names the time left, "Clear lockouts" lifts them.
10 state running == 1
+1 expect "Lock out for good" enabled equals "false"
+1 expect "Clear lockouts" enabled equals "false"
+1 state fact.scan.lockouts.count == 0
+1 slider "Squelch" 1.0
+5 state squelchDb > -10
+1 type "Start MHz" "100.2"
+1 key enter
+1 type "Stop MHz" "100.4"
+1 key enter
+1 type "Step kHz" "100"
+1 key enter
+1 type "Dwell ms" "300"
+1 key enter
+1 click "Start scan"
+30 state scanner == 1
+1 state fact.scanner.listMode != 1
# the keys are live in a range scan
+10 expect "Lock out for good" enabled equals "true"
+1 click "Lock out for good"
+20 state fact.scan.lockouts.count == 1
+1 state lanec.locktext == "1 locked out"
+1 click "Lock out 10 min"
+20 state fact.scan.lockouts.count == 2
+1 state fact.scan.lockouts.next > 0
+1 state fact.scan.lockouts.next <= 600
+1 state lanec.locktext contains "2 locked out"
+1 state lanec.locktext contains "ends in"
+1 expect "Clear lockouts" enabled equals "true"
+1 click "Clear lockouts"
+20 state fact.scan.lockouts.count == 0
+1 state lanec.locktext == ""
+1 click "Stop scan"
+30 state scanner == 0
