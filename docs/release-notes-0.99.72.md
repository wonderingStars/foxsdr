**The Plugin store is laid out like a store now, and the Fitted modules window like an operating panel.** The store opens on BROWSE: the catalogue in sections by category (aircraft, marine, satellites and weather, meters and paging, voice and data, maps and tools), each plugin a card with a small drawing, its name, one line about it, a badge when it has never decoded a real signal (EXPERIMENTAL) or has no build for your system (WINDOWS ONLY, LINUX ONLY), and one key: GET, FITTING... while it downloads, INSTALLED, or UPDATE with the two versions beside it ("1.8.0 to 1.8.1"). A key that cannot act is greyed and says why when you rest the pointer on it. A click on a card opens the plugin's page: its pictures first, then what it does, what is new in this version, the maker's legal notice where there is one (with a tick the key waits for) and, under SHOW DETAILS, the facts - maker, licence, plugin ABI, size, the SHA-256 of the build, and what the module says it reaches. Only three plugins have pictures yet; every other page says "No pictures published yet". The UPDATES tab lists what you are behind on, with the first line of what is new and an UPDATE ALL key. A plugin is now recognised as installed by its id and version, not by its file name, so a newer one in the catalogue shows as an update to the one you have. The last catalogue FoxSDR read is kept in the plugins folder and shown at once the next time; if a refresh then fails, the list stays and the top bar says so in amber ("Catalogue from 2026-10-07; could not refresh: ...") instead of the store going empty. The catalogue is still contacted only when you open the store for the first time in a session or press CHECK AGAIN, and nothing is fetched at start-up. A plugin's pictures are fetched only when you open its page, one at a time, over https, at most 4 MiB each, and each must hash to the SHA-256 the catalogue published before it is kept. An update that succeeds removes that plugin's older copy by itself, as it has since 0.99.50, UPDATE ALL included; this release adds a test of it on real modules. The Fitted modules window is rebuilt too: five filter chips with counts (FED, NOT DECODING, TAKES NO SIGNAL, STOPPED, REFUSED), one row per module with STOP or START and REMOVE, which asks twice, and a page per module that opens with what is true on this machine; the old data plate is gone, and the store window now remembers its size and place as the Fitted modules window already did. The catalogue's entries can now also carry a category, an experimental flag, a what's-new text, a publication date, pictures and the capabilities each plugin declares; a catalogue without them still reads, and an entry with a bad picture loses that picture, not the plugin. Nothing is signed, nothing is sandboxed - a fitted module runs inside FoxSDR with every privilege FoxSDR has, and its page says so beside the list of what it declares it reaches - and nothing updates itself.

Still not fixed, and known: the two fast-fail deaths reported from the field (0.99.64 on an RSP1 after 48 minutes, 0.99.65 on an RTL-SDR after 12 seconds) are not explained - since 0.99.69 every report names the other programs' DLLs in the process, and since 0.99.66 the sentinel names the faulting module, so the next one says more; the other twenty-eight languages' airband strings were not reviewed, and Italian and Dutch call the frequency list "Segnalibri" and "Bladwijzers" where German, French and Spanish call it by a name of its own, a difference older than 0.99.65 that was followed, not resolved; a recording whose disk disappears part way ends as an empty file with nothing on screen saying so; an MP3 patch speaker whose folder is removed says nothing; a log file held open by another program at start-up is silently switched off; the rtl_tcp source's Stop and Start keys in the window itself, and its Linux build, have not been tried against a real server; the store's new words are in all thirty-three languages but no native speaker has reviewed them in any of them; the public catalogue carries no categories yet, so BROWSE files every plugin under OTHER until it is republished with them; a plugin from the regional list shows no pictures; no picture has yet been fetched from the live catalogue over the network (the tests fetch from a stand-in server); and the new windows have not been built or run on Linux, nor looked at at a display scale other than 100%.
