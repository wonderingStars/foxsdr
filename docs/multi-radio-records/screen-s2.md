## What was built where

New: `src/slint/lanes2_logic.{hpp,cpp}` (pure rules), `lanes2_publish.{hpp,cpp}` (the `LaneS2` global, row lists, the engine commands, the zoom picture, the autosave and the log), `lanes2_folder.{hpp,cpp}` (the real Windows folder chooser, behind a function), `ui/lane_s2.slint` (two panels), `src/core/colour_maps_named.hpp` (generated by `tools/gen-named-colour-maps.py`), `tests/test_slint_lanes2_host.cpp`, drives `s2-spectrum`, `s2-files`, `s2-tuning`, `s2-colour-maps`, `s2-touch`, and the cost scripts `drive/measure/s2-off.txt`, `s2-on.txt`, `run_s2_cost.bat`.
The rows READ the engine's receiver state (`spectrumFftSize`, `spectrumWindow`, `spectrumFrameRateHz`, `ctun`, `vfoActive`, `vfoOther*`, `tunedHz`, `demodMode`) every tick and its facts (`radio.<n>.zoom`, `record.nameTemplate`), so a change made elsewhere shows at once; a typed value that has not been sent is a draft and is never saved. Nothing writes to the disk until the person switches the autosave or the log on (both off at every start). No engine command was added: every operation already existed (`SET_SPECTRUM`, `SET_IF_ZOOM`, `SET_CTUN`, `VFO_SELECT`, `VFO_SWAP`, `VFO_STORE`, `SET_FREQUENCY`, `SET_MODE`, `SET_BANDWIDTH`).
Legacy has none of these controls, so there were no ranges or words to match; ranges are the engine's (FFT 1024..131072, window 0..4, frame rate 0 or 1..120, zoom 256..16384 points and 100 Hz upwards).

## Test seams (inert in a normal run)
* `FOXSDR_S2_TOUCH_TEST=1` sets `SpectrumEvents.touch-test`, read ONLY when `bounded.bounded()` (a bounded run is one the harness starts; a normal run never reads the variable); with it false (always, in a normal run) a drag takes the zone-5 path only for an event that carries a touch finger id.
* `FOXSDR_S2_FOLDER_STANDIN` answers the folder chooser, only in a bounded run (a relative value is under the run's profile folder); a normal run calls the real Windows folder picker (`lanes2_folder.cpp`), UNVERIFIED until the mouse drive.
* `FOXSDR_SLINT_S2_OFF=1` (bounded only) leaves lane S2's tick and frame hook out, for the frame-cost comparison.
