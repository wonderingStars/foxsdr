# Screen hand-off M: the controls the second passes of wire-a, wire-b and wire-c added and no screen draws yet

Written by engine merge 4 (2026-11-13) from the SCREEN HAND-OFF sections of `wire-a.md` (12.3), `wire-b.md` (6.8) and `wire-c.md` (section 11, "SCREEN HAND-OFF for these rows"). The earlier lists are `screen-handoff-L.md` and the first-pass sections of the same three records; nothing from them is repeated here. English strings are the lanes' own; none is translated. Every operation is a `FOXAPP_OP_*` of `src/core/app_commands.hpp` (the wire-a numbers also in `src/core/wire_a_ops.hpp`). "Lane" is the source lane: A = wire-a, B = wire-b, C = wire-c.

DUPLICATE marks: no control is offered twice by two of the three lanes. Two pairs are RELATED but not duplicates, and are marked so a screen lane draws each once and does not merge them: the level store (A, spectrum levels per radio, memory, 250 ms rows) and the sweep history (B, the lines of a sweep device, memory, a file save); and the I/Q-file transport bar (A) beside the stitched sweep's "play" of a file radio (B refuses a retune on a radio playing a file). Operation numbers: A 0x8826-0x8831 (twelve), B 0x8931 (one), C 0x8A10 (one, the open-confirm); no value is defined twice (checked in `engine-merge-4.md`).
