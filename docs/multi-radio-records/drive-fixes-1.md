### Item 1, what was changed
* `SizeMirror` (look_logic.hpp): with the system's own scale it writes every tick as before. With another scale it writes nothing while a size the host asked for has not arrived (10 ticks at most), remembers the size when it writes a changed number and puts that size back next tick if the write moved the window.
* The grow for a scale (`applyLook`) is kept at least the smallest window (`kMinWindowW` x `kMinWindowH`, 1024 x 640) in LOGICAL pixels at the new scale and never larger than the work area of the monitor the window is on (`gaps_win.cpp windowWorkArea`); where both cannot hold (250 % on 1920 x 1080) the screen wins. Ctrl+0 / Auto returns to the automatic size (`ScaleFollower::sizeAfter` remembers it). The drag edges no longer write `win-w` themselves.
* New read-only drive states `look.physw`, `look.physh`, `look.maximised`.
* The hidden desktop's window is NOT maximised (the older `system-look` drive believed it was): see "Expectations changed".

### Item 8, what the code says
The palette's PLUGIN row only shows the DECODE bank (`main.cpp`, the `PLUGIN` rows of `rebuildPalette`): no retune, no start. The retune and the start came from pressing the plugin's PRESET key, which the tooltip names ("Tune to 931.9375 MHz, start this plugin and open the Decoder output window", `kit_logic.cpp presetTooltip`): `Engine::applyPluginPreset` (engine.cpp 4765) retunes, pins that ONE plugin to Always and raises FOXAPI_EVENT_PRESET_APPLIED; the window then opens the plugin's windows, for a text decoder the Decoder output window (`kit_publish.cpp` 214 to 231). While that window is open the window reports FOXAPP_PLUGIN_USE_DECODER_OUTPUT for EVERY decoder / I/Q-decoder plugin (`kit_logic.cpp pluginUseText`, the same as the classic `app_window_plugin_use.cpp` line 70), and the engine wakes every AUTO plugin that signal names (`engine_plugin_run.cpp` 403, `core/plugin_run.hpp` "decoderOutput"). So 66 decoders at 931.9375 MHz NFM is the designed consequence of "the Decoder output shows every decoder". Design written in `core/plugin_run.hpp` and the preset tooltip. NOT CHANGED. For the owner: the Decoder output could wake only the plugin whose preset opened it, or the plugins pinned to Always; with 66 decoders on one NFM channel the audio underruns reached 94. The count 66 is the drive's; not recounted here.
