**Bench meters now have a choice of style.** Right-click the Sample Rate meter or the Volume meter to pick how it is drawn: Classic (the existing bar), Analogue needle (a dark needle sweeping a dial, with a red zone that follows the arc), LED ladder (a row of segments), or Peak meter (a bar with a held peak marker). Each meter remembers its own style independently, so the Sample Rate meter and the Volume meter can be set differently, and the choice is saved with the rest of the configuration. All four styles show exactly the same reading - only the drawing changes. Requested by an Italian user.
